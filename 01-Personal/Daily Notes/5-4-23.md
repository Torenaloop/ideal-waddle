**"Too Many Emails? Use these proven techniques | Outlook tips included" - Leila Gharani**
 
- Inbox Zero technique
- Use of flagging/search tools to search for items (opposite of Inbox Zero)
 
- Develop an email routine - stop constantly checking your inbox; dedicate 10 minutes an hour to answering email
    - Turn off email notifications
    - Try "turning on" work offline in Outlook and then turn it "back on" to check email
   

- Create a folder system that works for you
    - Action-based folder structure - limited number of folders
      
    
- Apply Single Touch Rule to Avoid re-reading emails
    - Decide what to do with email when received
        - Do it now - Answer then decide to archive or delete
        - Reference (Archive) - can be found in search
        - Delete what you don't need now
      
    - Quick Answer Not Possible - can neither answer right away nor delete
        - Create an Action Required Folder and subsequent Quick Step and shortcut key combo
    - Delegate task to someone
        - Forward
        - Flag
    - Only you can get it done
        - Drag message down to calendar icon
        - Use scheduling assistant to find the right time to work on
    - Set start folder as Action Required folder
        - File \> Options \> Advanced \> Outlook Start and Exit \> Select Folder \> Start in this Folder \> Select Action Required Folder
      
    
- De-clutter Inbox - Use Rules
    - Triggers
        - Can get very specific (see advanced rules)
        - Create a CC Folder/Rule
        - Conditional Formatting - Color Code CC Messages
            - View, View Settings, Conditional Formatting, Add, Assign Name, Click on Font, Click on Condition, click on "where I am" on the CC line with other people, Ok, OK
          
**Take Control of Your Calendar**
 
- Personalize your calendar
    - Set working days and hours
        - Outlook Options, Calendar, Work time (check days, drop down of hours, first day of work week)
    - Shorten appointments and meetings
        - Outlook Options, Calendar, Calendar Options
    - Different time zones
        - Calendar settings, Time Zones (up to 3 different)
    - Add week numbers and weather to your calendars
        - Calendar Settings, Display Options, Show Week numbers
        - Calendar Settings, Display Options, Weather
    - Conditional Formatting (Ex: Meeting organized by boss)
        - Calendar View, View Settings, Conditional formatting, Add to create new rule, name and pick color, assign condition, Organized by - list name of person, click OK
          
        
- Schedule Meetings
    - Open Second Window
        - While in Outlook (email), right click on Calendar Icon - "Open in New Window"
            - Don't click on X in upper right to close, go to file and exit and it will remember to bring up 2 windows next time Outlook is opened
            - Right click icon method also works for Tasks and Contacts
    - Duplicate Meetings
