## Dataview Queries

### Upcoming Celebrations
```dataview
TABLE Date, Type, Status
FROM #celebration
WHERE Date >= date(today)
SORT Date ASC
LIMIT 5
```

### 2024 Celebrations Complete
```dataview
TABLE Date, Type
FROM #celebration
WHERE Year = 2024 AND Status = "Complete"
SORT Date DESC
```

### Active Gift Lists
```dataview
TABLE Year, Status, file.lists as "Items"
FROM #gift-ideas
WHERE Status != "Complete"
SORT Year DESC
```
