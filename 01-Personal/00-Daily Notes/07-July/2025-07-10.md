 


Yes—you can effectively turn a note into a folder in Obsidian, but it requires a community plugin since it isn’t a built-in feature.

  

  

  

  

🧩 Plugin Options

  

  

  

1. 

Folder Notes

 (by LostPaul)

  

  

- Attaches a note directly to a folder.
- Clicking the folder opens the note; optional Alt/Ctrl‑click to collapse content.
- Auto-syncs note name with folder, supports templates, hides the note file, and can convert existing folders into folder‑notes  .
- Offers a command: Make Current Note to Folder—creates a folder matching the current note’s name and moves the note into it ().

  

  

  

2. 

Folder Note Plugin

 (by xpgo)

  

  

- Similar to above:  
    

- Ctrl‑click a folder to add a “description note”
- Auto-create and sync names
- Choose placement methods (inside/outside/index-note)
- Supports templating and overview blocks  .

-   
    

  

  

  

3. 

Note‑Folder‑Autorename

  

  

- A lightweight plugin that promotes a note into a folder-and-note container. Useful if you follow a per-note attachments strategy  .

  

  

  

  

  

📌 How to Set Up Folder Notes

  

  

1. Go to Settings → Community Plugins → Browse.
2. Search for “Folder Notes” or “Folder Note”, then install and enable it.
3. Open the plugin’s settings to customize click behavior, templates, sync, and how folder‑notes are displayed.
4. Use the command palette (Ctrl/Cmd + P) to execute Make Current Note to Folder (or similar, depending on the plugin).

  

  

  

  

  

🔄 Without Plugins?

  

  

You’d have to manually:

  

1. Create a folder.
2. Move your .md note into that folder.
3. Optionally rename the .md file to something like index.md.
4. Manually link back to that note in your parent folder.

  

  

But this lacks the helpful automation and UI integration of the plugins.

  

  

  

  

✅ Summary

  

  

- To convert notes into folder‑based containers, your best bets are Folder Notes or Folder Note Plugin.
- If your goal is a per-note attachment folder, Note‑Folder‑Autorename is lightweight and tailored to that use.
- These plugins make the folder act and feel like the note itself in Obsidian’s explorer.
