## Project Overview

### Purpose
Conduct comprehensive third-party environmental compliance audits across all STACK data center operations to ensure regulatory compliance, identify gaps, and maintain baseline for continuous improvement.

## Power BI Dashboard Technical Requirements

### Critical Understanding ✅
**What matters for dashboard**:
- ✅ Findings spreadsheet format (MUST match 2022-2023)
- ✅ Column structure (cannot change)
- ✅ Picklists for categorical data
- ✅ Consistent naming conventions
- ✅ Standardized date formats
- ✅ Static file paths

**What doesn't affect dashboard**:
- ❌ Audit question wording
- ❌ Topics or subtopics
- ❌ Site-specific protocol variations

### Data Quality Controls
**David Nuckolls responsible for**:
1. **Lock down spreadsheets** - prevent unauthorized modifications
2. **Socialize to Ops EHS team** - "no going rogue" with spreadsheet manipulation
3. **Maintain consistency** - all data entry must be uniform
4. **Use picklists** - wherever categorization is needed
5. **Static file path** - source data location cannot change

## Historical Context & Lessons Learned

### 2022-2023 Audit Cycle
**What worked well**:
- Antea Group familiarity with STACK operations
- Power BI dashboard for visualization
- Standardized findings spreadsheet

**Challenges encountered**:
- Spreadsheet format inconsistencies caused dashboard issues
- Reverse-engineering audit scope from findings was difficult
- Need for stronger data quality controls

### 2025 Improvements
**Enhanced controls**:
- ✅ Emphasis on picklists from the start
- ✅ Clear separation: audit questions (flexible) vs. findings format (rigid)
- ✅ Proactive lock-down of spreadsheets
- ✅ Better team socialization on "no going rogue"
- ✅ Dedicated dashboard coordination meetings
