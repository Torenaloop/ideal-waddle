## Training Highlights

### Problem Statement & Value Proposition
**Key Message:** Asana connects tools, doesn't replace them.

### Core Concepts

#### Task Management Basics
- Each line is a task
- Additional details associated with each task:
  - Properties
  - Links
  - Attachments
- Commenting and '@-ing' people
- For larger tasks, use sub-tasks

#### Multi-Select & Bulk Actions
**How to multi-select:**
1. Select the 6 dots on left side of task
2. Press and hold Shift
3. Drag down to select multiple tasks

**Use for:** Bulk editing, moving, assigning tasks

#### Assign Copy Function
Copy tasks with all details and settings to quickly duplicate work.

**Use case:** Templates, recurring work patterns

---

## Customization Features

### Custom Fields
Add custom properties to tasks for your specific needs.

**Example:** Priority, Status, Department, etc.

**Where to find:** Look for "Add custom field" button

**Value:** Tailor Asana to your workflow

### Views: Sort, Group, Filter

#### Sort
Sort tasks by any field (e.g., priority, due date, assignee)

#### Group
Group tasks into sections based on field values (e.g., group by status)

#### Filter
Show only tasks meeting specific criteria (e.g., "only assigned to me")

**Strategic Use:** Customize view for your specific needs at any moment

---

## Advanced Task Features

### Multi-Homing Tasks
Tasks can appear in multiple projects simultaneously.

**How:** Add task to additional project  
**Benefit:** Task appears in multiple places, updated everywhere  
**Advanced:** Can delineate into specific section of a project

**Use case:** Cross-functional work, tasks relevant to multiple initiatives

---

## My Tasks & Inbox

### My Tasks
**Critical Concept:** Should be your single source of truth for what you have to do.

**Contains:**
- Project-based tasks
- Stand-alone tasks

**Task Visibility Column:** Control where tasks appear

**Strategy:** Use My Tasks as personal command center

### Inbox Management
**Three Actions for Notifications:**
1. **Read & Archive** - Simple FYI notifications
2. **Additional Work Required** - Add detail or give a like, then archive
3. **Create Follow-Up Task** - Convert notification to actionable task
