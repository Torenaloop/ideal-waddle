## Compliance Requirements for APs

### Documentation Standards

**ISO requires APs to include:**
- Clear purpose and scope
- Roles and responsibilities
- Step-by-step procedures
- Resources and references
- Review and approval process
- Version control

---

## Compliance Checklist

### ERP ISO Compliance
- [ ] Scope & Purpose clearly defined
- [ ] All potential emergency scenarios identified
- [ ] Clear responsibilities assigned
- [ ] Step-by-step response protocols
- [ ] Communication protocols documented
- [ ] Resources identified (contacts, equipment, facilities)
- [ ] Training requirements and schedule defined
- [ ] Testing/drill frequency specified
- [ ] Post-emergency review process
- [ ] Maintenance and update process
- [ ] Proper version control
- [ ] Accessible to those who need it

### BCP ISO Compliance
- [ ] Business impact analysis completed
- [ ] Recovery strategies defined
- [ ] Continuity protocols documented
- [ ] Required resources identified
- [ ] Stakeholder notification plans
- [ ] Exercise program defined
- [ ] Review and update process
- [ ] Integration with ERP
