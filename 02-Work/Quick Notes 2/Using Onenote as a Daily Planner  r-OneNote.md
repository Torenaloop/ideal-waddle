I have been long trying to find a solution for the best way to track tasks and notes for a given day, and toying with the idea of Onenote as a planner.  
Using pre-made planners did not quite work for me, mainly because it took too much effort and I ended up with a lot of empty pages. I don't need to fill the personal planner out every day (work is a different thing) and a lot of these planners felt overdone.  
I finally settled on a set up that works great for me... hopefully it will help someone else.  
So, the key elements:

1. Month calendar. I downloaded an Excel spreadsheet that creates a monthly calendar for any given month, and formatted it to have long dates in the individual cells (i.e. "Wednesday, December 1, 2021" instead of "01"). I copy that calendar to Onenote page for December.
2. I created a "Daily Planner" template with calendar like hour slots on the left, and Tasks (to do today and next steps) and Notes on the right. I set it as the default template for the new pages in section.
3. When I have something for a specific date, I navigate to the Month and put double square brackets around that date in calendar. This automatically creates a new page using Daily Planner template, with date as its title (that's why I am using long dates) and a link from Month to that day. So, by looking at Month, I can immediately see what days in the calendar table have planner pages associated with them (they have links) and can click on them to go to that day.
4. At work, when I have meetings, I drag them from Outlook into the time slot in Daily Planner. Then I can launch them directly from Onenote. (It also helps to concentrate on important meetings, as I have several meetings every day that I was copied on but don't necessarily plan on attending). If any meeting requires planning / prework, I create a separate page for it, either indented under the day page, or in the corresponding job notebook & linked back to that day. Any tasks from my task list that I plan on doing that day are also copied into Day Planner, and if I have time I will set up the links back to the original task in Todoist. This helps to keep everything related to a specific day in one place. (For personal stuff I don't bother with that level of integration).
5. Creating Todoist tasks from Onenote is quick thanks to AutoHotKey integration.
6. Once my Planner grows, I plan on using Onemore to create a table of contents with links back to pages. (For now, there's no point in it).
7. I make extensive use of custom tags and plaintext tags to find stuff scattered across days.
8. Onetastic Calendar is a helpful additional tool, which can be used to see what note was edited on what day.
9. Finally, there's now a way to set up reminders in Onenote using Onemore add-in. I don't use it because I need alerts on my mobile devices, but for someone who's primarily working with a Windows device this could be of value.

So far, it worked great. If there was a way to add reminders on Onenote for mobile devices (iOS specifically), it could replace a lot of other apps and services.  
Next steps: Goals, Projects, closer integration with personal records.
