### ✅ Based on your context, here are Asana setup best practices for your org:

#### 🧱 1. Start with a clear hierarchy:

| Asana Level | Your Use |
| --- | --- |
| **Team** | "EHS Department" (or separate for Construction vs. Ops) |
| **Projects** | For each major initiative, recurring workflow, or program (e.g. "Site Safety Audits", "Training Rollout Q4", "Incident Response Improvements") |
| **Tasks** | Specific actions within those projects |
| **Sections** | Use for stages (Planning, In Progress, Complete) or categories (Audits, Docs, Training, Compliance) |
| **Custom Fields** | Add fields like `Priority`, `Project Type`, `Region`, `Owner`, etc. for database-style filters |

---

#### 🔁 2. Use Multi-Homing Smartly:

- **Multi-home tasks** into both a functional project (e.g. “Monthly Compliance Reviews”) *and* a strategic overview board (e.g. “All Active Initiatives”).
- Let stakeholders see the same task from different perspectives (e.g. Directors see grouped by initiative; team sees grouped by execution plan).

---

#### 🧭 3. Create cross-functional views:

Use **Saved Reports** (via Advanced Search) for:

- All “High Priority” tasks across EHS
- Tasks by assignee or subteam
- Stalled tasks (no due date, overdue, or untouched for X days)
- Director-specific dashboards (filtered by custom field or project tag)

---

#### 📊 4. Leverage Dashboards & Reporting:

- Build **Dashboards** per Director or Program (status, blockers, overdue tasks, completion rate)
- Use **Milestones** for tracking large deliverables
- Integrate with **Goals** if your org aligns on quarterly/annual outcomes

---

### ⚠️ Common Pitfalls to Avoid:

| Mistake | Fix |
| --- | --- |
| **Too many small projects** | Use *sections and custom fields* inside a few well-scoped projects instead |
| **No ownership on tasks** | Always assign an *owner and due date* for accountability |
| **Mixing personal to-dos in team projects** | Use *My Tasks* for personal work; don't clutter shared projects |
| **Overengineering custom fields** | Only add fields that are filterable/report-worthy; don’t overwhelm the team |
| **Underutilizing templates** | Standardize repeatable workflows like "New Site Audit" or "EHS Training Launch" |
